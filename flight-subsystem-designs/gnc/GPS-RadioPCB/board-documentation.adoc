Global Navigation and Communications Board.

Purpose and Overview: 
Provides power to Space Maniac's Celeste (GNSS Receiver) and Murgas (UHF/VHF transceiver), and interfaces their control, networking and data lines with Cubesat PC104. 
Features the Texas Instruments LMK class Clock signal Fanout buffer chip, to produce 3 separate copies of PPS (Pulse Per Second) signal, from GNSS receiver, whch is critical for timing.

Individual Parts Justification : 
1.
1G pin 10k Pull up resistor, this protects chip during power-up and power-down. High level input voltage is 0.75 x VDD = 2.475 and high level input (Leakage) current is 50 micro A. Input Leakage Current is the current that flows into pin transistor when not actively driven internally. 2.475, the high level input voltage is the threshold to be recognised as high. 3.3V - 10k x 50mu = 2.8 > 2.475. So this resistance value is used.

2.
I2C Pull up resistor of 3.3 k Ohm to 3.3 V recommended

3.
CAN requires 120 KOhm terminal Resistor

4.
Fanout Chip Power Supply requires Decoupling capacitors and Inducting ferrite bead, It is recommended that The distance between the Capacitors and Power supply be as close as possible. 

5.
Ext Reset EPC2014 MosFET is needed near the GNSS Ext RST pin, to use this feature.
